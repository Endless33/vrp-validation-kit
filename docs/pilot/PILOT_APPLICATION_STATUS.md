# VRP Pilot Application Status

**Status:** SUSPENDED  
**Effective:** 21 August 2026  
**Project:** VRP — Veil Routing Protocol  
**Maintainer:** Vitalijus Riabovas

---

## Pilot Applications Are Suspended

Effective immediately, new applications for the VRP Pilot are no longer being accepted.

VRP is entering a restricted development phase.

There is currently **no announced date** for reopening Pilot access.

This does not mean that VRP development has stopped.

**Development continues privately.**

---

## What Changes Now

From 21 August 2026:

- New Pilot applications are not accepted.
- No Pilot slot can be reserved.
- Previously published application deadlines should no longer be treated as active access guarantees.
- No reopening date is guaranteed.
- Regular public project updates are no longer guaranteed.
- Public repositories and validation material may remain available, change, or become unavailable in the future.
- Previous Pilot terms should not be assumed to apply if access reopens.

The project is under no obligation to maintain a permanent public evaluation window.

---

## Public Validation Material

Material that remains publicly available may still be used to inspect and evaluate the public VRP validation boundary.

This includes, where available:

- validation tools;
- Docker scenarios;
- evidence artifacts;
- verification tools;
- audit material;
- technical documentation.

However, public access to these materials does **not** constitute an invitation to the VRP Pilot.

It does not reserve future access.

It does not provide access to the protected VRP runtime.

---

## Protected Runtime

The VRP implementation remains black-box.

The following remain private:

- protected runtime implementation;
- proprietary continuity mechanisms;
- internal protocol logic;
- private engineering methods;
- non-public security and runtime components.

The public validation boundary exists to allow observable behaviour to be tested without disclosing protected implementation details.

That boundary remains in force.

---

## Existing Application Routes

Previously published application forms or application instructions should not be interpreted as currently open enrollment.

Submitting an old form does not:

- create a Pilot reservation;
- establish priority;
- guarantee review;
- guarantee future participation.

If VRP Pilot access is reopened, the project will define the applicable process at that time.

---

## Future Pilot Access

No reopening date is currently announced.

If Pilot access returns, the conditions may change substantially.

Future access may include:

- invitation-only participation;
- stricter organisation verification;
- additional technical qualification;
- additional security requirements;
- reduced Pilot capacity;
- different commercial terms;
- revised evaluation boundaries;
- a new application process.

There is no guarantee that previous Pilot conditions will return.

---

## Public Communication

VRP is also moving away from a fixed public communication schedule.

There is no longer a guaranteed Monday, Wednesday, or Friday publication schedule.

Technical updates may appear when there is something I decide should be made public.

That could be tomorrow.

It could be months from now.

Some development may never be publicly disclosed.

Public silence should therefore not be interpreted as abandonment of the project.

**VRP development continues.**
